# Attendees must be provided with pre-printed badges

**Status:** Approved

All attendees, organisers and volunteers must be provided with identifying badges / lanyards for the following reasons:

* Ensures that all people at the event are meant to be there and security / volunteers can easily identify attendees.
* Acts as attendee identification in the case of any code of conduct violations.
* Act as a visual proof of the conference being a private event (this can be required in some locations to be able to make certain decisions that might not be legal for a public event, such as gender neutral toilets in some US states).

The badges don't need to be anything fancy or expensive, as long as they're not self-written by the attendees themselves. For example, a pack of lanyards and badge sleeves plus some badges printed on plain paper is sufficient if budget is limited.
